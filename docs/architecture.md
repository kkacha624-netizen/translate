# 要件定義

## 目的・ユースケースの定義

### 解決したい課題
1. 英語論文で、意味をとることができない
2. 論文を読む集中力が続かない
3. 専門用語が分かりにくい
4. 図と本文のつながりが分からない
5. 引用論文とのつながりが分からない
6. 論文の中で提唱されている数式が合っているのか分からない

### 課題の原因
|対応する課題|課題の原因|
|---|---|
|1 2 3 4|思考を日本語ベースで行っているので、いちいち頭の中で翻訳を実行し、その間にそれまでのことを忘れてしまう, 文字数制限で一度に翻訳を行うことができない|
|2|翻訳を行う別タスクで疲れてしまう|
|5| 5を除く1~6の課題があり、引用元の論文も十分に理解できていない
|5 6|DeepLやGoogle翻訳でPDF翻訳を行うと$\LaTeX$の構造が壊れてしまい、意味がとりにくくなる|
